# FoodBridge – Smart Food Donation and Redistribution

**Problem Statement:** PS-08 – Food Donation and Redistribution

## Team Details
- Participant 1: SAGILI VARSHINI
- Participant 2: SISTLA NANDINI

## Problem
A large amount of surplus food from restaurants, hotels and events is wasted every day, while many people struggle to access sufficient food. There is a need for a platform that connects food donors with NGOs to reduce food waste and support people in need.

## Proposed Solution
FoodBridge is a food donation and redistribution platform that connects food donors with NGOs. Donors can list surplus food, and NGOs can browse available donations and request food. Once the donor approves a request, pickup contact details are shared so that food collection can be coordinated.

## Key Features
- Add surplus food donations.
- Browse available food donations.
- Search and filter food by category and location.
- Request food donations through the NGO interface.
- Accept or reject donation requests.
- View pickup contact details after approval.
- Track food collection status.
- View donation and impact statistics.

## Technology Stack
- Frontend: React.js, Tailwind CSS
- Backend: Not implemented
- Database: Browser LocalStorage
- APIs / AI tools: ChatGPT assistance during development
- Hosting: Not deployed yet

## Application Workflow
1. User opens FoodBridge.
2. User selects Donor or NGO role.
3. Donor adds available surplus food.
4. NGO browses available food.
5. NGO requests a donation.
6. Donor approves the request.
7. NGO receives pickup contact details.
8. Food is collected and the status is updated.

## Installation and Setup
1. Clone the repository.
2. Open the project folder in VS Code.
3. Install dependencies using `npm install`.
4. Start the application using `npm run dev`.
5. Open the localhost URL displayed in the terminal.

## How to Use
- Select the Donor role to add food donations.
- Select the NGO role to browse and request food.
- Donors can manage donation requests.
- After approval, NGOs can access pickup details.
- Update the donation status after collection.

## Known Limitations

- Data is stored in browser LocalStorage.
- No backend or cloud database is connected.
- Donor and NGO roles are simulated.
- Data is not synchronized between different users or devices.
